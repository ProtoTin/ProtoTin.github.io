Methodology & disclosure

What this assessment represents

This educational tool samples selected outcomes from the NIST CSF 2.0 Core. It is not an official NIST assessment, compliance audit, certification, or substitute for a complete organizational profile.

The four maturity labels reference NIST CSF Tiers, while the numeric averaging and roadmap prioritization are project-specific methods created for this demonstration.

Scenario, direction, and content by Tin Aung. Design and code created with OpenAI Codex. No assessment data leaves the visitor’s browser.
